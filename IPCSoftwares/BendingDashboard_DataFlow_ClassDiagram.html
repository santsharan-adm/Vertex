📊 Data Flow Sequence (One Complete Cycle)

Step Component Action Data Format Timing
1 PlcClient ReadHoldingRegistersAsync from PLC via Modbus TCP ushort[] raw registers ~90ms loop
2 PlcClient Fires OnPlcDataReceived(plcNo, Dict<uint, object>) Dict keyed by Modbus address → ushort[] Immediate
3 DashboardInitializerBase Calls _algo.Apply(plcNo, rawData) Raw registers passed to algorithm Immediate
4 AlgorithmAnalysisService ConvertData → ApplyScaling → OnPlcDataProcessed(tagId, val) Typed: float, bool, string, int Per tag
5 DashboardInitializerBase latestValueNew[tagId] = value (central cache updated) Dict<int, object> Continuous
6 DashboardInitializerBending _bendingProcess.Process(latestValueNew) — FIFO logic Updates internal BatchModel queue 500ms loop
7 SafePollerEx (UI) Timer fires → CoreClient.GetIoValuesAsync(requestId) RequestPackage { RequestId=11 } 500ms loop
8 CoreClient → UiListener TCP send JSON request → server receives JSON serialized RequestPackage <1ms
9 UiListener Calls OnRequestReceived(request) → HandleUiRequest RequestPackage → ResponsePackage <5ms
10 DashboardInitializerBending Builds model from latestValueNew / _bendingProcess DashboardInspectionModel / BendingIndicators etc. <1ms
11 UiListener → CoreClient TCP send JSON response back to UI JSON serialized ResponsePackage <1ms
12 SafePollerEx → ViewModel Deserializes response → calls ViewModel callback Typed model objects Immediate
13 Dashboard2ViewModel Updates ObservableProperties → WPF Data Binding UI renders updated values Dispatcher
