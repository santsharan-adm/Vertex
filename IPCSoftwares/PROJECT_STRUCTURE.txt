Key Components:
===============

MODELS LAYER:
- LotModel (125 lines)
  * Represents manufacturing lot with QR codes
  * Stores temperature and pressure arrays
  * Tracks creation time and status

- SystemStateModel (40 lines)
  * TT-1 positions: tt1_pos0, tt1_pos1, tt1_pos2, tt1_pos3
  * TT-2 positions: tt2_pos0, tt2_pos1, tt2_pos2
  * Collections: CompletedLots, ProcessEvents
  * Counters: CycleCounter, TimeCounter

- BindingParametersModel (115 lines)
  * INotifyPropertyChanged implementation
  * Properties: LotId, Temp1-4, Pressure1-4, QRCode1-4
  * Auto-binding to XAML TextBlocks with StringFormat

- LotManager (55 lines)
  * Static factory creating 10 pre-configured lots
  * QR code generation: ABCD{i}2345A{j}
  * Temperature variation: 80-84°C
  * Pressure variation: 6.8-7.2 N

VIEWMODELS LAYER:
- BaseViewModel (32 lines)
  * INotifyPropertyChanged interface implementation
  * SetProperty<T> helper method for change tracking
  * OnPropertyChanged virtual method

- MainViewModel (380 lines)
  * Core application logic
  * Timer management (2-second intervals)
  * Lot movement orchestration
  * Parameter display updates
  * Event logging system
  * Data binding properties for UI

VIEWS LAYER:
- MainWindow.xaml (450+ lines)
  * Header: Status and cycle information
  * Top Section: 3 parameter tiles (Bending 1, 2, 3)
  * Middle Section: Input Robot, TT-1, Transfer Arrow, TT-2, Output Robot
  * Bottom Section: Scanned Parts table, Process Events table
  * All elements bound to ViewModel properties

- MainWindow.xaml.cs (24 lines)
  * Window initialization
  * DataContext binding to MainViewModel
  * Shutdown cleanup

CONVERTERS:
- BoolToColorConverter (35 lines)
  * Converts position active state to visual color
  * Active = Green (#10B981)
  * Inactive = Blue (#3B82F6)
  * Used in Canvas Ellipse fill bindings

Features Implemented:
====================

✓ 10 Pre-configured Lots (LOT-001 to LOT-010)
✓ Unique QR Codes (4 per lot)
✓ Temperature Parameters (4 values, 80-84°C range)
✓ Pressure Parameters (4 values, 6.8-7.2 N range)
✓ Real-time Simulation (2-second updates, 4-second movements)
✓ TurnTable Position Tracking (TT-1: 4 positions, TT-2: 3 positions)
✓ Parameter Display System (Dynamic updates based on lot position)
✓ Event Logging (Entry, Bending, Transfer, Exit events)
✓ Process Tracking (Completed lots, Process events)
✓ Visual Indicators (Color-coded position indicators)
✓ Robot Status Displays (Input and Output robots)
✓ Tables (Scanned Parts, Process Events with data binding)
✓ MVVM Architecture (Full separation of concerns)
✓ Data Binding (Two-way binding with StringFormat converters)
✓ Responsive UI Layout (Grid and DockPanel based)
